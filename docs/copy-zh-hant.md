## 3. 怎麼玩

**區塊標題：** 怎麼玩

1. **瀏覽** — 在裝備目錄裡找裝備：工具、相機、露營用品、遊戲、樂器等等。可以依類別和地區篩選。
2. **排隊** — 把想借的東西加進你的排隊清單。如果它正借出中，你的位置會保留。等它空出來，就輪到你。
3. **借用** — 出借人核准你的申請後，你們約好交接的時間和地點。拿到手，用起來，好好享受。
4. **歸還** — 依拿到時的狀況還回去。出借人標記為已歸還，排隊清單裡的下一位就上場了。

**結尾句：** 有東西在積灰塵嗎？[刊登它](/list)，讓別人也用得上。

## 6. 損壞賠償價說明

**標題：** 什麼是損壞賠償價？

每一則刊登都有損壞賠償價。這是物品損壞或遺失時，借用人同意付給出借人的金額。

- **出借人** 在刊登時設定。要合理：依維修費用或重置價值來定。
- **借用人** 在送出申請前就看得到，不會有意外。
- **如果出了狀況，** 出借人會在物品歸還時標記為「損壞」，並適用損壞賠償價。
- **付款是你們兩人之間的事。** 本站不收款、不代管金錢，也無法強制付款。好好溝通，講道理，直接結清。

正常耗損不算損壞。拿不準的話，交接時和歸還時都拍照留存。

**短版（用於提示框／申請步驟）：** 損壞賠償價：這件物品損壞或遺失時，你要付給出借人的金額。由你們兩人直接結清。

## 6c. 常見問題：損壞賠償價

**誰來設定損壞賠償價？**
出借人在刊登物品時設定。你在送出申請前就能在刊登頁面上看到，事先心裡有數。

**誰來收錢？本站會收款嗎？**
不會。本站從不收取、保管或轉交任何款項。如果物品被標記為損壞或遺失，借用人和出借人會直接結清損壞賠償價。本站無法強制付款，所以請保持友善，講道理。

**怎麼定一個合理的價格？**
依維修或重新購買的費用來定，哪個比較實際就用哪個。如果是舊東西，可以參考同類二手貨的價格。定得太高會把借用人嚇跑；定得太低，萬一出事你就得自掏腰包。在刊登內容裡簡單寫一下物品狀況，對雙方都有幫助。

**如果什麼都沒壞呢？**
那就什麼都不用付。只有出借人在歸還時把物品標記為損壞或遺失，才需要支付損壞賠償價。如果東西好好地回來了，出借人會標記為「完好歸還」，誰都不用付錢。正常耗損不算損壞。

## 需要協調／程式碼配合的問題（譯者註）

1. **「[message removed]」**：資料庫（`supabase/05-messages-and-deletion.sql`）把已刪除使用者的訊息內文直接寫成英文字面值 `[message removed]`。中文介面要顯示「[訊息已刪除]」，需要程式碼在顯示時辨識並替換這個值。第 15、17.7 節目前保留英文原樣，與實際顯示一致；如果程式碼支援替換，再統一改為「[訊息已刪除]」。
2. **DELETE 確認詞**：保留英文 `DELETE`，因為程式碼依這個字串精確比對。若想讓中文使用者輸入「刪除」，需要程式碼支援。
3. **{time left}、{amount} 的格式**：中文介面需要「5 小時」「2 天」這樣的時長格式，以及與語言相符的金額格式（貨幣符號、千分位）。需要程式碼依語言格式化。
4. **{listing / user}**：中文需要兩句完整句子（「檢舉這則刊登」／「檢舉這位使用者」），量詞不同（則／位），不能只做字串拼接。
