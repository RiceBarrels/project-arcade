## 수집하는 정보

- **계정 정보:** 이메일 주소(가입 시 인증)와 로그인 정보.
- **프로필:** 표시 이름, 도시 또는 지역, 그리고 본인이 추가하기로 선택한 그 밖의 프로필 정보.
- **게시글:** 제목, 설명, 카테고리, 상태, 픽업 지역, 본인이 정한 가격(이용료와 파손 배상금), 본인이 업로드한 사진.
- **대여 기록:** 요청, 대기열 등록, 승인, 전달 및 반납 표시(문제없음 또는 파손), 관련 메모.
- **신고:** 본인이 보낸 신고, 그리고 본인이나 본인의 게시글에 대해 접수된 신고.
- **의견:** 의견 보내기를 이용하면 메시지, 선택한 유형(버그, 아이디어 또는 기타), 이용 중이던 페이지, 브라우저에 관한 간단한 정보를 저장합니다. 로그인한 상태라면 본인의 계정과 연결됩니다. 답변받을 연락처를 추가하면 그 연락처도 저장합니다. [TO CONFIRM: 정확한 저장 항목. 이 문구를 작성할 당시 아직 존재하지 않았던 supabase/08-feedback.sql을 근거로 함.]
- **기본 기술 데이터:** 이용자가 사이트를 방문하면 저희의 호스팅 및 분석 제공업체가 기본적인 기술 정보를 처리합니다. 예를 들어 이용자가 본 페이지, 대략적인 위치(국가 또는 지역), 브라우저와 기기 종류 등입니다. 아래 "분석 도구와 쿠키"를 참고하십시오. [TO CONFIRM: Vercel과 Supabase의 서버 로그 및 IP 주소 처리 방식. NEEDS REVIEW.]

## 저장 위치

계정, 프로필, 게시글, 대여 기록, 사진은 Supabase(데이터베이스, 인증, 파일 저장소)에 저장됩니다. 데이터는 캐나다(Supabase 리전 ca-central-1)에 저장됩니다. 웹사이트는 Vercel에서 호스팅됩니다.

## 다른 이용자에게 보이는 정보

이용자의 공개 프로필은 다른 이용자에게 보입니다. 공개 프로필에는 표시 이름, 도시 또는 지역(추가한 경우), 소개, 가입한 연도와 월, 그리고 게시글과 그 사진이 표시됩니다. 또한 간단한 개수도 표시됩니다: 등록한 물건, 빌려준 물건, 빌린 물건의 수, 문제없이 반납된 물건의 수, 그리고 파손 또는 분실된 물건의 수(빌려주는 사람일 때와 빌리는 사람일 때 각각). 누구에게 빌려주었는지, 누구에게서 빌렸는지는 표시되지 않습니다. [NEEDS REVIEW: 2026-10-20에 components/profile-stats.tsx와 프로필 페이지를 기준으로 확인함. 프로필이 바뀌면 다시 확인할 것.] 정확한 주소는 게시글에 적지 않아야 합니다. 이메일 주소는 절대 공개적으로 표시되지 않습니다. 요청이 승인되면, 빌려주는 사람과 빌리는 사람은 사이트의 앱 내 메시지로만 서로 연락합니다.

## 분석 도구와 쿠키 (초안, 검토 필요)

저희는 사이트의 어느 부분이 이용되는지 알기 위해 Vercel Web Analytics로 페이지 방문 수를 집계합니다. Vercel의 문서(문서 "Privacy and Compliance"(개인정보 보호 및 규정 준수), 최종 수정일 2026-06-26)에 따르면 다음과 같습니다:
- Vercel Web Analytics는 제3자 쿠키를 사용하지 않습니다. 방문자는 들어오는 요청으로부터 만든 해시로 구별됩니다.
- 방문자 세션 정보는 영구적으로 저장되지 않으며, 24시간이 지나면 폐기됩니다.
- 누구든 이용자를 여러 웹사이트나 앱에 걸쳐 추적할 수 있게 하는 정보는 수집하지 않으며, 합산된 통계에만 사용됩니다.
- 각 페이지 조회에는 다음이 포함될 수 있습니다: 시각, 페이지 경로, 참조 페이지(리퍼러), 대략적인 위치(국가, 지역, 도시), 운영체제와 버전, 브라우저와 버전, 기기 종류(모바일, 태블릿 또는 데스크톱).

페이지 조회 정보가 전송되기 전에, 저희는 페이지 경로에서 물건, 대여, 프로필 ID를 제거하고, 쿼리 매개변수와 # 기호 뒤의 모든 내용을 제거합니다. 저희가 보내는 이메일의 링크(가입 링크나 비밀번호 재설정 링크를 누르면 열리는 /auth/... 페이지)는 전혀 보고되지 않으며, 그 밖의 페이지는 /en/login과 같이 경로만 보고됩니다. 저희는 이용자 ID를 보내지 않습니다. 참조 페이지는 분석 도구가 자체적으로 포함하는 것이므로 저희가 변경할 수 없습니다. [NEEDS REVIEW: 2026-10-20에 개발자가 코드를 확인한 결과를 근거로 함.]

저희는 이 정보를 광고 표시에 사용하지 않으며, 판매하지도 않습니다.

쿠키: 사이트는 작동하는 데 필요한 쿠키만 설정합니다(두 종류이며, 비공개 베타 기간에는 한 종류가 더 있습니다).
- 로그인 쿠키는 저희의 로그인 제공업체(Supabase)가 설정하며, 이용자의 로그인 상태를 유지합니다. 이 쿠키는 여러 부분으로 나뉠 수 있습니다.
- 언어 쿠키는 이용자가 선택한 언어를 기억합니다. 이 쿠키는 1년 동안 유지됩니다.
- 비공개 베타 비밀번호가 켜져 있는 동안에는 pa_access라는 접근 쿠키가 이용자가 비밀번호를 입력했다는 사실을 기억합니다. 이 쿠키는 30일 동안 유지되며 개인정보를 담고 있지 않습니다. 비밀번호가 꺼지면 저희는 이 쿠키를 더 이상 설정하지 않습니다. [NEEDS REVIEW: 쿠키 이름, 30일 유지 기간, "비밀번호가 켜져 있는 동안에만"이라는 내용은 코디네이터의 브리핑을 근거로 함. 아직 코드에서 확인하지 않음.]

사이트는 또한 이용자의 "탭할 때 진동" 설정, 테마 선택(라이트 또는 다크. 시스템으로 그대로 두면 아무것도 저장되지 않습니다)과 온보딩 화면 진행 상황을 이용자 본인 기기에 있는 브라우저의 로컬 스토리지(local storage)에 저장합니다. 이는 쿠키가 아니며 저희에게 전송되지 않습니다.

저희는 광고 쿠키나 사이트 간 추적 쿠키를 설정하지 않습니다. [NEEDS REVIEW: 2026-10-20에 개발자가 코드를 확인한 결과를 근거로 함. 무언가가 추가되면 다시 확인할 것.]

[TO CONFIRM: 위 문서 페이지에는 나와 있지 않으므로 Vercel 또는 대시보드에서 확인할 것: (1) IP 주소가 저장되는지, 아니면 대략적인 위치를 파악하는 데에만 잠시 사용되는지; (2) 합산된 분석 데이터를 얼마나 오래 보관하는지; (3) 분석 데이터가 어디에 저장되고 처리되는지. 확인하기 전에는 이에 관한 내용을 게시하지 말 것.]

## 이용 목적

사이트 운영: 게시글 표시, 대기열과 요청 관리, 빌려주는 사람과 빌리는 사람이 서로 연락할 수 있도록 지원, 신고 처리, 사이트 안전 유지.

## 하지 않는 일

- 이용자의 데이터를 판매하지 않습니다.
- 광고를 표시하지 않습니다.
- 사이트는 결제를 받지 않으므로 카드나 은행 정보를 수집하지 않습니다.

## 공유

사이트 운영에 필요한 서비스 제공업체(데이터베이스 및 호스팅 제공업체 등)와 데이터를 공유합니다. 법률상 요구되는 경우 정보를 공개할 수 있습니다. [TO CONFIRM / 변호사: 처리업체(수탁자) 전체 목록.]

**이메일 발송(Resend) (초안, 검토 필요).** 저희는 Resend를 이용하여 이용자의 계정에 관한 이메일을 보냅니다: 이메일 인증, 비밀번호 재설정, 보안 알림. 이 이메일은 no-reply@project-arcade.ricebarrel.com 주소에서 발송됩니다. 이메일을 보내기 위해 Resend는 이용자의 이메일 주소와 메시지 내용을 받습니다. 저희는 이용자의 계정과 관련된 이메일을 보내는 데에만 Resend를 사용하며, Resend는 그 목적으로만 이용자의 이메일 주소를 받습니다. 저희는 마케팅 이메일을 보내지 않습니다. Resend의 개인정보 처리방침에 따르면, Resend는 데이터를 미국으로 이전하여 그곳에서 처리합니다. [TO CONFIRM: Resend에서 확인할 것: (1) Resend가 저희의 처리업체(수탁자)로서 역할을 하는지, 그리고 데이터 처리 계약이 체결되어 있는지; (2) Resend가 발송된 이메일의 내용과 로그를 얼마나 오래 보관하는지(Resend의 개인정보 처리방침에는 기간이 나와 있지 않음); (3) Resend의 하위 처리업체(resend.com/legal/subprocessors에 목록이 있음). 국외 이전 관련 문구는 변호사가 확인할 것.]

## 데이터 보관과 삭제

*의견:* 계정을 삭제하면 본인이 보낸 의견은 보관되지만 더 이상 본인과 연결되지 않습니다. [TO CONFIRM: supabase/08-feedback.sql의 `user_id ON DELETE SET NULL`과 일치하는지. 보존 기간, 그리고 답변 연락처도 함께 삭제되는지.]

계정 설정에서 직접 계정을 삭제할 수 있습니다. 삭제하면 프로필, 등록한 물건과 그 사진, 대기열 내 자리가 삭제됩니다. 대기 중이거나 승인된 요청은 종료되고, 본인이 보낸 메시지의 텍스트는 "[message removed]" 표시로 대체됩니다. 대여 기록(물건 이름, 날짜, 파손 배상금, 파손 메모, 상태), 대화에서 상대방이 보낸 메시지, 신고는 보관되지만 더 이상 본인과 연결되지 않습니다. 현재 전달된 상태의 물건이 있으면 계정을 삭제할 수 없습니다. [TO CONFIRM: 로그와 보관 기록을 얼마나 오래 보존하는지. 법적 보존 의무가 있는지 변호사가 확인할 것. 아직 실행되지 않은 supabase/05-messages-and-deletion.sql을 근거로 함.]
